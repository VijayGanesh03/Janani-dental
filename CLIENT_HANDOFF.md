## Run locally

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run dev`.

## Production

Run `npm run build` to create the production output. The project is suitable for a Cloudflare-compatible Node deployment. Keep the included package files and hosting configuration together when moving it.
